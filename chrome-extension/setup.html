Canvas Pro Capture

Save images, directly downloadable video and audio, screenshots, links, and readable web content into your Mac library.

Connect once

  1. Install and open Canvas Pro in Applications.
  2. Run the supplied install-extension-bridge setup if it has not already been installed.
  3. Load this extension using Chrome → Extensions → Developer mode → Load unpacked.
  4. Click the toolbar icon. The status should say Connected.

Capture methods

Right-click an image, video, audio player, link or selected text to save it. From the toolbar, capture the visible page, drag a screenshot region, collect up to 100 images, find videos and animated media, or save the page’s readable text and source information. Captures show a right-side activity panel with download progress and results. Canvas Pro icons on X/Twitter, Instagram, Reddit and Pinterest save media from the clicked post.

What stays private

Captures travel through Chrome’s native messaging connection to Canvas Pro on your Mac. There is no account, analytics service or cloud upload. Small content scripts add save buttons to supported social feeds. Other pages are inspected when you invoke a capture; it does not request access to all your browsing history or run on every website in the background. Network requests retrieve public post metadata and media when you save. Optional deep scanning asks for site access and observes media response URLs only on the tab you enable, for up to 30 minutes; it ends on navigation or can be stopped from the popup. It does not read cookies or authorization headers.

Video limits

The extension downloads direct HTTP/HTTPS media files exposed by the page. When a player uses a blob URL, discovery can recover its underlying public media file. Pure in-memory blobs, DRM, encrypted streams, HLS/DASH assembly and media requiring browser login cookies are not supported. Some Reddit fallback files omit separate audio; the capture panel warns when that fallback is used. Use a screenshot or save the page link when a site blocks a download. Direct video capture is limited to 1 GB per file; images and audio to 100 MB.

Some pages restrict extensions

Chrome’s internal pages, the Chrome Web Store, and certain embedded cross-origin frames do not allow page inspection. Return to a regular webpage and try again. Discovery includes loaded media, exposed lazy sources, media metadata and background images. Scroll or play media before scanning if a page has not exposed its source.
